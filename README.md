# Tech Services - Advanced Backend

موقع ويب احترافي متكامل مع Backend متقدم

## المميزات الجديدة ✨

### 🗄️ قاعدة البيانات MongoDB
- نماذج بيانات متكاملة
- علاقات بين الجداول
- حفظ دائم للبيانات

### 🔐 نظام المصادقة JWT
- تسجيل دخول آمن
- JWT Tokens
- حماية المسارات

### 📧 إشعارات البريد Nodemailer
- إيميلات تلقائية
- تأكيد الطلبات

### 👨‍💼 لوحة تحكم Admin
- إدارة الطلبات
- إحصائيات مفصلة

### 💳 نظام الدفع Stripe
- معالجة المدفوعات

### 💬 دردشة مباشرة Socket.IO
- محادثة فورية

## التثبيت 🚀

1. npm install
2. إعداد MongoDB
3. npm run seed  (إنشاء admin)
4. npm start
